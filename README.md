📋 Sobre el proyecto

Margaret es un mini proyecto de gestor de tareas desarrollado como práctica de programación y gestión de bases de datos.

La aplicación permite trabajar con tareas desde una interfaz sencilla, utilizando Python como lenguaje principal y una base de datos MariaDB para almacenar la información.

🛠️ Tecnologías utilizadas
🐍 Python — Desarrollo y lógica de la aplicación.
💻 Visual Studio Code — Entorno de desarrollo.
🗄️ MariaDB — Base de datos.
🟠 XAMPP — Entorno local para trabajar con la base de datos.
🔵 HeidiSQL — Gestión y administración de la base de datos.
